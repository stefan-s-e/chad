# chad
## An idiosyncratic CLI time-tracking software written by hand.

Never experience hanging chads on your timecard again.

## Background

**chad** is a Python program which you interact with through the terminal. 

## Usage

The UI is an interactive menu in the style of bash "select" menus and man pages. Depending on the option chosen, the menu can be multi-level, as in an automated phone menu. **chad** maintains a local database in the form of a text file which can be manually manipulated if desired.

Run **chad** by opening a terminal in the top-level directory and typing **python3 main.py**.

## Dependencies

None but `python3`.
